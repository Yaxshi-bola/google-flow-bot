# ⚡ Google Flow Video Generator Telegram Bot (Render.com)

Bu bot kompyuter va Chrome o'chiqligida ham **24/7 rejimida Render bulutida** ishlaydi va Google Flow orqali videolarni avtomatik tayyorlab, Telegramingizga yuboradi.

## Telegram Bot:
- **Username:** `@sdkjgnsjgbot`

## Buyruqlar:
- `/start` — Botni ishga tushirish va holatni ko'rish
- `/status` — Navbatdagi videolar va joriy progress
- `/cookie <matn>` — Google Flow cookie'sini kiritish
- `/clear` — Navbatni tozalash

Istalgan promptni (masalan: `Cinematic drone shot of mountains...`) yuboring, bot videoni tayyorlab Telegramingizga yuboradi!
